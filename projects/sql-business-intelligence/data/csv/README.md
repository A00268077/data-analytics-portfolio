# Dataset

This project uses a synthetic e-commerce dataset designed to simulate a realistic multi-market retail business.

## Dataset Size

- 3,000 customers
- 250 products
- 15,000 orders
- 37,892 order line items
- 2,079 returns
- 30 employees
- 8 countries
- Date range: 2022–2025

## Tables

- customers
- orders
- order_items
- products
- categories
- suppliers
- employees
- regions
- shippers
- payments
- returns

The dataset is synthetic and was created specifically for SQL and Business Intelligence portfolio analysis.
